# Quest Hz Hub

A standalone HTML/CSS/JS reference site for Meta Quest refresh-rate and frame-pacing ADB commands.

## Run
Open `index.html` in a browser. No build step is required.

## Important
The site distinguishes:
- Native display refresh rates
- Effective FPS created by refresh-rate + swap-interval combinations

Commands can change across Horizon OS versions. Verify the actual result on the headset.
